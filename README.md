# Know Brampton

An independent, plain-language civic guide to Brampton, Ontario — in English and Punjabi.
Not affiliated with or endorsed by the City of Brampton.

- `etl/`  Python pipeline that pulls public data into `data/` (committed, so git history is the audit trail)
- `data/` normalised JSON, regenerated by `python -m etl.run`
- `web/`  Next.js static site, two locales (`en`, `pa`)
- `docs/` plan, sourcing policy, translation glossary

## Run the pipeline
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r etl/requirements.txt
python -m etl.run
```
